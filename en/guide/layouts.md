# Layouts

If a keyboard supports more than one layout, the preset layout options make it easy to switch to the layout you actually built.

Choose "Layouts" in the feature menu on the left; the panel lists every layout option the keyboard supports. Turning these options on and off switches the layout — for example split backspace versus 2U backspace, or ANSI Enter versus ISO Enter.

Changes take effect and are saved to the keyboard immediately, without any extra save step.
