# v4 changelog

## 4.0.7 (2026-09-15)

### Features

- Support for configuring encoder (knob) keys
- Bluetooth host management for LINK protocol v3
- The number of Bluetooth hosts now comes from the firmware
- Device information shows the Marin firmware release version (for example 2025.01)
- Overall interface layout refresh
- Dependency updates

### Bug Fixes

- Several issues in keyboard layout handling
- Home page background rendering

## 4.0.6 (2026-05-17)

### Bug Fixes

- Fixed the firmware version display
- Fixed a defect in the OTA firmware update

## 4.0.5 (2025-12-08)

### Features

- Macros: added keycode search, with suggestions appearing as you type

## 4.0.4 (2025-10-28)

### Features

- Added device connection monitoring; the keyboard has to be connected again after it disconnects

## 4.0.3 (2025-10-08)

### Features

- New keycode group: Windows Radial
- Dependency updates

A guide for Windows Radial keycodes and firmware will follow in the documentation

## 4.0.2 (2025-6-24)

### Bug Fixes

- Fixed an issue when switching between connected devices

## 4.0.1 (2025-6-12)

### Features

- Upgraded the macro module for Marin Firmware with support for delay and text
- Added window size detection
- Added debouncing for window size changes

### Bug Fixes

- Performance improvements

## 4.0.0 (2025-4-26)

### Breaking Changes

- Redesigned the whole UI
- Rebuilt the project on the WebHID API and WebBluetooth API
- Runs in the browser without installation
