# Getting Started

## Before you start

Before using LINK, please check the [browser compatibility table](https://developer.mozilla.org/en-US/docs/Web/API/WebHID_API#browser_compatibility).

## Use it online

You can try LINK directly at [link.lnelab.com](https://link.lnelab.com).

## Still using LINK+?

LINK+ is essentially a desktop application for Windows and macOS.

::: warning
The offline LINK+ is no longer maintained — we recommend the web version of LINK
:::

You can download LINK+ in three ways:

- [Releases on GitHub](https://github.com/lnelab/link-plus/releases)
- [Releases on Gitee](https://gitee.com/lne-lab/link-plus/releases)
- [Official QQ group 1107582873](https://qm.qq.com/cgi-bin/qm/qr?k=yh-g8ixY1X2Agzi5h-agoCCJDgVaL5in&jump_from=webapi)

::: tip
link-plus-win-x.x.x.exe is the build for Windows

link-plus-mac-x.x.x.dmg is the build for macOS
:::

### Installation

Download the package that matches your operating system.

- On Windows, double-click the installer after the download finishes and complete the one-click setup.

- On macOS, double-click the package after the download finishes and drag the application on the left into the folder on the right.

## Compatibility

LINK supports keyboards based on the LNE solution (Marin) or QMK Firmware. Please make sure your device meets the requirements before using LINK.

LINK recognizes keyboards automatically. Connect the keyboard to your computer over USB, then click "Connect device" on the home page and pick your keyboard; you can then personalize every parameter of it.

If the built-in definition library does not cover your keyboard, you can import a definition file manually so that LINK recognizes it correctly, or contact LNE Lab for official support.
