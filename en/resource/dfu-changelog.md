# Firmware changelog

This page lists every Marin Firmware release. The version is the release month (for example `2026.09`), the same numbering that LINK shows in Device information.

Packages are available in the [firmware library](/en/resource/dfu-package); the upgrade steps are in [Firmware update](/en/guide/dfu).

## 2026.09

**Keyboards** Hammer, Ursa Major (left / master) · **Released** 2026-09-22 ~ 2026-09-26

- Bluetooth host management: pair, keep and switch between several host slots (use LINK 4.0.7 or later)
- Improved multi-host Bluetooth advertising and the standard Bluetooth identity list
- Fixed LINK responses while the Bluetooth output is active
- Fixed the reported firmware version
- Support Windows Radial keys and an encoder
- Hammer: new keyboard support
