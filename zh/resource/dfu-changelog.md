# 固件更新日志

这里记录 Marin Firmware 固件包的发布记录。版本号即发布的年月（例如 `2026.09`），与 LINK「设备信息」中显示的固件版本是同一套编号。

更新包在[固件升级库](/resource/dfu-package)中下载，升级方法见[固件升级](/guide/dfu)。

## 2026.09

**涉及机型** Hammer、Ursa Major（左 / 主控） · **发布日期** 2026-09-22 ~ 2026-09-26

- 新增蓝牙主机管理，支持多个主机位的配对、保存与切换（配合 LINK 4.0.7 及以上使用）
- 改进多主机蓝牙广播与标准蓝牙身份列表
- 修复蓝牙输出生效时 LINK 响应异常
- 修正固件版本显示
- 支持径向控制器（Windows Radial）按键与编码器
- Hammer：新增机型支持
