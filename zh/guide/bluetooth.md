# 蓝牙

蓝牙面板用于管理键盘与各台主机（电脑、手机等）之间的无线连接，包括切换主机位、设置休眠时间以及重置配对信息。

::: tip
该面板只会在支持蓝牙的机型上出现（由键盘定义决定）。主机位列表需要键盘固件支持 LINK 协议 v3 及以上，协议版本可以在[设备信息](./device)中查看。
:::

## 电池模式

当前固件下电池模式固定为「自动」，由固件根据连接状态与功耗自动管理。

## 休眠时间

键盘在一段时间无操作后会进入休眠以节省电量。可以在下拉框中选择 10、15、30 分钟，或 1、2、4、8 小时。实际生效的休眠策略由固件决定。

## 主机

「主机」区域用于管理键盘可以连接的多个主机位，每个主机位会显示自己的状态：

- **当前** —— 键盘此刻连接的主机
- **已配对** —— 该主机位保存了配对信息，点击即可切换过去
- **空闲** —— 该主机位还没有配对信息，需要使用键盘上的配对组合键进行配对

主机位的数量由固件决定。点击右上角的刷新按钮可以重新读取各主机位的状态，例如刚用键盘上的配对键配对了新的主机之后。

::: tip
固件协议版本低于 v3 时，这里只会显示一个主机位下拉框，无法查看各个主机位的配对状态。
:::

## 配对

点击「重置配对」会清除**所有**主机位保存的蓝牙配对信息，之后需要重新配对。

::: warning
该操作会影响键盘上保存的全部主机，而不只是当前连接的那一台，并且无法撤销。
:::
